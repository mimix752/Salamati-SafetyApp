  Méthode 1 - Même WiFi:
  ──────────────────────
    1. npm run dev
    2. Noter l'adresse Network (ex: http://192.168.1.10:5173)
    3. Sur mobile: ouvrir cette adresse
    4. Installer l'app


  Méthode 2 - Ngrok (depuis n'importe où):
  ─────────────────────────────────────────
    Terminal 1:  npm run dev
    Terminal 2:  ngrok http 5173
    
    → Ouvrir l'URL https://xxx.ngrok.io sur mobile
    → Installer l'app

  Ngrok:
  ──────
    ngrok http 5173             # Tunnel public
    ngrok http 5173 --region eu # Serveur européen

  🔍 TROUVER VOTRE ADRESSE IP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Windows:
  ────────
    ipconfig
    
    → Chercher "Adresse IPv4" (ex: 192.168.1.10)


  Mac:
  ────
    ifconfig | grep inet
    
    → Ligne "inet 192.168.x.x" (pas 127.0.0.1)


  Linux:
  ──────
    ip addr show
    hostname -I
    
    → Première adresse (ex: 192.168.1.10)

  Erreur "Cannot find module":
  ─────────────────────────────
    rm -rf node_modules
    npm install


  Port 5173 déjà utilisé:
  ───────────────────────
    npm run dev -- --port 3000


  Connexion refusée depuis mobile:
  ─────────────────────────────────
    1. Même WiFi?
    2. Pare-feu désactivé?
    3. Essayer: npm run dev -- --host


  Build échoue:
  ─────────────
    npm cache clean --force
    rm -rf node_modules dist
    npm install
    npm run build


  Service Worker ne fonctionne pas:
  ──────────────────────────────────
    Chrome DevTools → Application → Service Workers
    → Cliquer "Unregister" puis recharger
