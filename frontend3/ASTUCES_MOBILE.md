# 💡 Astuces et Conseils - Salamati Mobile

## 🎯 Optimiser l'Expérience Mobile

### 1. 🔋 Économiser la Batterie

L'application Salamati est optimisée pour consommer peu de batterie, mais voici quelques astuces:

- ✅ **Mode Sombre**: Activez le mode sombre de votre téléphone (économise jusqu'à 30% de batterie sur OLED)
- ✅ **Fermer les onglets**: Fermez les autres onglets du navigateur après installation
- ✅ **Utiliser en mode PWA**: L'app installée consomme moins qu'en version navigateur
- ✅ **Géolocalisation**: N'activez le GPS que quand nécessaire

### 2. 📱 Accès Ultra-Rapide au SOS

**Créer un raccourci direct:**

#### Sur Android:
1. Installez l'app normalement
2. Maintenez l'icône Salamati sur l'écran d'accueil
3. Créez un widget (si disponible) pour accès encore plus rapide

#### Sur iOS:
1. Après installation, ajoutez un widget Siri
2. Configurez "Hey Siri, ouvre Salamati"
3. Accès vocal instantané!

### 3. 🔐 Sécurité et Confidentialité

**Protéger vos données:**

- 🔒 **Code PIN**: Activez le verrouillage de votre téléphone
- 🔒 **Face ID/Touch ID**: Utilisez la biométrie pour plus de rapidité
- 🔒 **Masquer l'icône** (Android): Renommez l'app avec un nom discret via les paramètres
- 🔒 **Notifications discrètes**: Désactivez les aperçus de notifications

**Astuce:** Sur certains téléphones, vous pouvez masquer des apps dans un dossier sécurisé.

### 4. 📍 Améliorer la Précision de la Localisation

Pour que le bouton SOS envoie votre position exacte:

1. **Activez "Haute précision"** dans les paramètres de localisation
2. **Autorisez toujours** l'accès à la localisation pour Salamati
3. **En intérieur**: La précision peut varier (10-50m)
4. **En extérieur**: Précision de 5-10m généralement

**Test:** Avant une situation d'urgence, testez le bouton SOS dans différents endroits pour vérifier la précision.

### 5. 🎨 Personnalisation

**Adapter l'app à vos besoins:**

- ✅ Ajoutez jusqu'à 5 contacts d'urgence
- ✅ Organisez les contacts par priorité (le premier sera contacté en premier)
- ✅ Personnalisez le message d'alerte si besoin
- ✅ Testez les actions rapides (faux appel, alarme)

### 6. 🔔 Notifications et Alertes

**Préparer pour les urgences:**

1. **Volume maximum**: Configurez le volume pour l'alarme sonore
2. **Mode silencieux**: L'alarme fonctionne même en mode silencieux
3. **Notifications**: Autorisez les notifications pour les futures mises à jour

### 7. 📶 Utilisation Hors Ligne

L'app fonctionne **sans Internet** après installation:

- ✅ **Bouton SOS**: Fonctionne (SMS via réseau mobile)
- ✅ **Contacts**: Accessibles localement
- ✅ **Numéros d'urgence**: Pré-chargés
- ✅ **Assistant juridique**: Nécessite Internet (informations à jour)
- ⚠️ **Géolocalisation**: Fonctionne avec GPS (pas besoin d'Internet)

**Astuce:** En mode avion, désactivez l'avion mais gardez le WiFi éteint pour utiliser le GPS seul.

### 8. 🎭 Mode Discret

Pour utiliser Salamati discrètement:

1. **Renommez l'icône** (Android): Utilisez un nom neutre genre "Notes" ou "Calculatrice"
2. **Changez l'icône** (avec launchers Android): Utilisez une icône discrète
3. **Dossier caché**: Placez dans un sous-dossier d'apps peu utilisées
4. **Accès rapide**: Configurez un raccourci clavier ou gestuel (selon téléphone)

### 9. ⚡ Performances

**Maximiser la vitesse:**

- ✅ Fermez les apps en arrière-plan avant urgence
- ✅ Libérez de l'espace (minimum 500 MB recommandé)
- ✅ Redémarrez votre téléphone une fois par semaine
- ✅ Mettez à jour votre système d'exploitation

### 10. 🧪 Tests Réguliers

**Tester l'app régulièrement:**

- 📅 **Chaque mois**: Testez le bouton SOS (maintenez puis relâchez avant 3 sec)
- 📅 **Vérifiez les contacts**: Assurez-vous que les numéros sont à jour
- 📅 **Testez la géolocalisation**: Vérifiez que votre position s'affiche correctement
- 📅 **Alarme sonore**: Testez que le son fonctionne à volume max

## 🎓 Techniques Avancées

### Raccourcis iPhone (iOS)

Créez une **automation Siri** pour ouvrir Salamati avec un mot-clé:

1. App **Raccourcis** → Nouvelle automation
2. Déclencheur: "Quand je dis [mot-clé]"
3. Action: "Ouvrir Salamati"
4. Maintenant vous pouvez dire "Hey Siri, [mot-clé]" pour ouvrir l'app!

### Widget Android

Si vous savez coder, vous pouvez créer un widget Android personnalisé qui ouvre directement le bouton SOS.

### Tasker (Android) - Utilisateurs avancés

Automatisez avec Tasker:
- Secouez le téléphone 3 fois → Ouvre Salamati
- Appui long sur volume bas → Active SOS
- En dehors d'une zone sûre → Notification rappel

### Apple Watch (iOS)

Si vous avez une Apple Watch:
1. Ajoutez Salamati à vos apps watch
2. Accès instantané depuis votre poignet!

## 🌟 Meilleures Pratiques

### ✅ À FAIRE:

1. **Tester régulièrement** en situation non-urgente
2. **Prévenir vos contacts** qu'ils sont listés comme urgences
3. **Expliquer comment ça marche** à vos proches

5. **Activer la localisation** en permanence

2. **N'ajoutez pas** de contacts qui ne peuvent pas vous aider
3. **Ne comptez pas uniquement** sur l'app (ayez un plan B)
4. **Ne partagez pas** vos contacts d'urgence publiquement
5. **N'utilisez pas** en conduisant

## 🆘 Scénarios d'Usage

### Scénario 1: En Taxi/Uber
1. Dès que vous montez, ouvrez Salamati
2. Partagez votre trajet avec un contact
3. Si problème: maintenez SOS discrètement

### Scénario 2: Rendez-vous Inconnu
1. Programmez un faux appel (Action Rapide)

1. Activez le partage de localisation
2. Définissez un contact de sécurité pour la nuit
3. Testez le bouton SOS avant de sortir

### Scénario 4: Voyage
1. Ajoutez les numéros d'urgence locaux (déjà fait pour le Maroc!)
2. Partagez votre itinéraire avec 2-3 personnes
3. Vérifiez la couverture réseau de votre zone

## 📞 Support Technique

### Problèmes Connus

**iOS Safari - Géolocalisation:**
- Redémarrez Safari si la géolocalisation ne fonctionne pas
- Autorisez dans: Réglages → Safari → Localisation → "En utilisant l'app"

**Android Chrome - Installation:**
- Si "Installer" ne s'affiche pas, videz le cache
- Chrome → Paramètres → Confidentialité → Effacer données → Cache

**Vibration ne fonctionne pas:**
- Vérifiez: Paramètres → Sons et vibrations → Vibration activée
- Mode silencieux peut désactiver les vibrations

### Log de Debug

Pour signaler un bug, notez:
1. Modèle de téléphone
2. Version du système (iOS/Android)
3. Navigateur utilisé
4. Action effectuée avant le bug
5. Message d'erreur (si affiché)
