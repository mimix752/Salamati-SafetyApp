  L'app ne se lance pas?
  ──────────────────────
    → Vérifiez que Node.js est installé: node --version
    → Installez les dépendances: npm install
    → Relancez: npm run dev


  Impossible de connecter depuis mobile?
  ──────────────────────────────────────
    → Même WiFi que l'ordinateur?
    → Pare-feu désactivé?
    → Essayez Ngrok: ngrok http 5173


  "Installer" ne s'affiche pas?
  ─────────────────────────────
    → iPhone: utilisez Safari (pas Chrome!)
    → Android: utilisez Chrome (pas Samsung Internet!)
    → Rechargez la page


  Autre problème?
  ───────────────
    → Consultez: COMMANDES_RAPIDES.txt
    → Section "🐛 DÉPANNAGE RAPIDE"
