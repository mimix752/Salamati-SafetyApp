🚀 INSTALLATION RAPIDE (3 ÉTAPES)
═══════════════════════════════════════════════════════════════

ÉTAPE 1: Démarrer le serveur
────────────────────────────────────────────────────────────────
  npm run dev


ÉTAPE 2: Accéder depuis votre mobile
────────────────────────────────────────────────────────────────

  🔷 MÉTHODE A - MÊME WIFI (Recommandé pour test)
  
     1. Trouvez votre IP:
        Windows: cmd → ipconfig
        Mac/Linux: terminal → ifconfig
        
     2. Notez l'IP (ex: 192.168.1.10)
     
     3. Sur mobile, ouvrez: http://192.168.1.10:5173
  

  🔷 MÉTHODE B - NGROK (Accès partout)
  
     1. Téléchargez: https://ngrok.com/download
     
     2. Terminal: ngrok http 5173
     
     3. Copiez l'URL (ex: https://abc123.ngrok.io)
     
     4. Ouvrez cette URL sur mobile


ÉTAPE 3: Installer l'application
────────────────────────────────────────────────────────────────

  📱 ANDROID (Chrome):
     → Bannière "Installer Salamati" apparaît
     → Cliquez sur "Installer"
     → OU: Menu ⋮ → "Installer l'application"
  

  🍎 iPHONE/iPAD (Safari uniquement!):
     → Ouvrez dans Safari
     → Tapez bouton Partager 📤 (en bas)
     → "Sur l'écran d'accueil"
     → "Ajouter"

═══════════════════════════════════════════════════════════════
🔧 PROBLÈMES FRÉQUENTS
═══════════════════════════════════════════════════════════════

❌ "Impossible de se connecter"
   ✅ Vérifiez le même WiFi
   ✅ Désactivez le pare-feu temporairement
   ✅ Utilisez Ngrok

❌ "Le bouton Installer n'apparaît pas"
   ✅ iOS: Utilisez Safari (pas Chrome!)
   ✅ Android: Utilisez Chrome
   ✅ Rechargez la page

❌ "Géolocalisation ne fonctionne pas"
   ✅ Autorisez les permissions
   ✅ iOS: Réglages → Safari → Localisation
   ✅ Activez le GPS

❌ "Bouton SOS ne fonctionne pas"
   ✅ Ajoutez au moins 1 contact
   ✅ MAINTENEZ le bouton (ne tapez pas)
   ✅ Autorisez la localisation
