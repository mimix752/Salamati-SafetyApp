## 🚀 How to Run

### Quick Start (3 Steps)

1. **Navigate to project:**
   ```bash
   cd selmeti-mobile
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the app:**
   ```bash
   npm start
   ```

4. **Scan QR code** with Expo Go app on your phone!
