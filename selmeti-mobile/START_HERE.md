# 🛡️ SELMETI MOBILE APP - START HERE!

## 🎉 Welcome to Your Complete React Native App!

This is a **fully functional mobile safety application** for women in Morocco, built with React Native and Expo.

---

## ⚡ Quick Start (3 Commands)

```bash
cd selmeti-mobile
npm install
npm start
```

Then scan the QR code with **Expo Go** app on your phone!

---

## 📱 What Is This App?

**Selmeti** is a comprehensive safety application featuring:

- 🚨 **SOS Emergency Button** (triple-tap activation)
- 🧮 **Disguise Mode** (transforms into calculator)
- 💬 **AI Chatbot** (legal information & support)
- 📚 **Legal Resources** (Law 103-13 & rights)
- 👥 **Professional Support** (lawyers & psychologists)
- 📞 **Emergency Contacts** (manage & alert)
- ⚙️ **Settings** (language, security, etc.)

## 🚀 Installation

### Prerequisites
- Node.js (v16+)
- npm or yarn
- Expo Go app (on phone)

### Steps

**1. Navigate to project:**
```bash
cd selmeti-mobile
```

**2. Install dependencies:**
```bash
npm install
```

**3. Start development server:**
```bash
npm start
```

**4. Run on device:**
- Install **Expo Go** on your phone
- Scan QR code from terminal
- App will load on your phone!

## 🆘 Troubleshooting

### Can't install dependencies?
```bash
npm install --legacy-peer-deps
```

### Can't connect to Expo Go?
```bash
npm start -- --tunnel
```

### Need to clear cache?
```bash
npm start -- --reset-cache
```
